# 🌙☀️ Interactive Day/Night Theme Toggle

A beautiful interactive **day and night scene toggle** built with pure **HTML, CSS, and JavaScript**.

This project started as a simple light/dark theme button and evolved into a small animated world with a sky, moon, sun, stars, trees, clouds, a flower, and a moving astronaut. 🚀

## ✨ Features

- ☀️ Animated day scene
  - Sun with realistic shadows
  - Moving clouds
  - Growing flower animation
  - Trees changing color
  - Sky gradient transition

- 🌙 Animated night scene
  - Moon with crater details
  - Randomly generated stars
  - Star blinking animation
  - Flying astronaut
  - Dark atmospheric sky

- 🎨 Pure CSS illustration
  - No external UI libraries
  - Custom shapes created with CSS
  - Smooth transitions and animations

- ⚙️ JavaScript interactions
  - Dynamic star generation
  - Random star positioning
  - Preventing stars from appearing on the moon
  - Interactive theme switching

## 🛠️ Technologies Used

- HTML5
- CSS3
  - Animations
  - Transitions
  - Transformations
  - CSS shapes
  - Checkbox hack

- Vanilla JavaScript
  - DOM manipulation
  - Random generation
  - Event handling

## 🎯 Purpose

The goal of this project was to practice creating interactive interfaces without using frameworks and to explore how far HTML, CSS, and JavaScript can go when building visual experiences.
